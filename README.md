# 🔥 Sistema de Detecção de Chama com Arduino

Projeto acadêmico desenvolvido com **Arduino Uno** para detectar a presença de chama e acionar um sistema de alerta.

O sistema utiliza um **sensor de chama**, que realiza a leitura do ambiente. Quando uma chama é detectada, o Arduino aciona automaticamente o **servomotor, LED e buzzer**.

O projeto também possui um **botão para acionamento manual** do alarme.

## 🧰 Componentes

* Arduino Uno
* Sensor de chama
* Servomotor
* LED
* Buzzer
* Botão
* Protoboard
