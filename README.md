# 🔥 Sensor de Detecção de Incêndio por Temperatura

## 📌 Sobre o projeto

Projeto acadêmico desenvolvido com Arduino Uno para a criação de um sistema de detecção e alerta de incêndio baseado na temperatura do ambiente.

O sistema realiza a leitura da temperatura por meio de um sensor. Quando a temperatura atinge o limite definido na programação, o Arduino realiza automaticamente o acionamento do sistema de alerta.

O projeto também possui um botão para permitir o acionamento manual do alarme.

## ⚙️ Funcionamento

O funcionamento do sistema ocorre da seguinte maneira:

1. O sensor realiza a leitura da temperatura do ambiente.
2. O Arduino Uno recebe e processa essa informação.
3. O código verifica se a temperatura atingiu o limite estabelecido.
4. Caso o limite seja atingido, o sistema aciona o alarme.
5. O servomotor realiza o movimento da hélice.
6. O LED indica visualmente o acionamento do sistema.
7. O botão permite o acionamento manual do alarme.

## 🧰 Materiais utilizados

- Arduino Uno
- Protoboard
- Sensor de temperatura
- Servomotor
- Hélice
- Botão de acionamento manual
- LED
- Resistores
- Fios jumper

## 🔌 Montagem

O circuito foi montado utilizando uma protoboard para realizar a conexão entre o Arduino Uno, o sensor de temperatura, o botão, o LED e o servomotor.

O Arduino é responsável pelo processamento das informações e pelo controle dos componentes do sistema.
